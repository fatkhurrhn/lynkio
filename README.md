# Lynkio

**Lynkio** is a simple and organized link hub designed to collect and access various useful websites in one place.
It groups links into categories such as Anime, Manga, Games, Apps, and more, making navigation faster and easier.

Instead of searching for websites individually, Lynkio allows users to quickly open their favorite resources through a clean and categorized interface.

---

## ✨ Features

* 📂 Categorized link collections
* ⚡ Fast and lightweight interface
* 🎨 Clean UI built with TailwindCSS
* 🔗 Quick access to frequently used websites
* 🧭 Easy navigation between categories

---

## 🛠 Tech Stack

* **React** – Frontend library
* **Vite** – Fast development build tool
* **TailwindCSS** – Utility-first CSS framework
* **ESLint** – Code linting and formatting

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```
git clone https://github.com/yourusername/fadev-lynkio.git
```

### 2. Navigate to the project folder

```
cd fadev-lynkio
```

### 3. Install dependencies

```
npm install
```

### 4. Run the development server

```
npm run dev
```

Then open:

```
http://localhost:5173
```
